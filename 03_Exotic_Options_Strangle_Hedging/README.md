# Comparing Vanilla and Asset-or-Nothing Options on Strangle Strategy for Cocoa Price Hedging

**Authors:** Donny Citra Lesmana, Muhammad Harits Ramadhan, Farah Nurina Zhafira, Josephine Ayudhita Mawarni Sitorus, Ardenisa Dusi Santuni, Dianike Marsalisa Mayori, Randi Satria Purnama  
**Affiliation:** Department of Mathematics, IPB University

## Abstract
Cocoa prices exhibit high volatility due to production instability, requiring effective hedging strategies. This study compares two Long Strangle hedging strategies—one utilizing standard European Vanilla Options and another utilizing Binary *Asset-or-Nothing* Exotic Options—on Indonesian weekly cocoa spot prices (2021–2022) from BAPPEBTI. Normality of log-returns was verified via the Shapiro-Wilk test ($p\text{-value} = 0.9134$). Option premiums were valued under the Black-Scholes framework ($r = 5.75\%$, $T = 2\text{ months}$, $K_1 = \text{IDR } 32,000$, $K_2 = \text{IDR } 34,000$). Results demonstrate that if cocoa prices drop sharply below $\text{IDR } 27,822$, the Vanilla Strangle yields superior protection, whereas if prices rally above $K_2$ ($\text{IDR } 34,000$) or stay between $\text{IDR } 27,822$ and $K_1$, the Asset-or-Nothing Strangle delivers significantly higher profits.
