# 📊 Actuarial Modeling, Quantitative Finance & Data Science Portfolio
**Author:** Muhammad Harits Ramadhan (S.Si. - Actuarial Science, IPB University)

Welcome to my technical portfolio repository. This repository contains R scripts, statistical modeling workflows, machine learning pipelines, and quantitative finance research projects.

---

## 📂 Project Directory

1. **[01_BPJS_Healthcare_ML_Classification](./01_BPJS_Healthcare_ML_Classification)**
   * Supervised Machine Learning Classification (Logistic Regression, KNN, SVM, XGBoost, Decision Tree, Random Forest) on 100,000 sampled records from 4.05M BPJS Kesehatan FKTP visit logs (2015–2020).
   * Achieved top F1-Scores of **0.99699 (SVM)** and **0.99695 (XGBoost)** via 5-Fold Cross-Validation.

2. **[02_Cocoa_Hedging_Collar_vs_JadeLizard](./02_Cocoa_Hedging_Collar_vs_JadeLizard)**
   * Undergraduate Thesis evaluating multi-leg vanilla option hedging strategies (*Protective Collar* vs. *Reverse Jade Lizard*) on Indonesian spot cocoa prices (2019–2022) using Black-Scholes pricing.

3. **[03_Exotic_Options_Strangle_Hedging](./03_Exotic_Options_Strangle_Hedging)**
   * Comparative derivative pricing and payoff simulation between European Vanilla Options and Binary Exotic Options (*Asset-or-Nothing*) on a Long Strangle hedging structure.

4. **[04_TSLA_Binomial_Option_Pricing](./04_TSLA_Binomial_Option_Pricing)**
   * Numerical 100-step Binomial Lattice option valuation and convergence simulation on Tesla (TSLA) stock data fetched via `quantmod`.
